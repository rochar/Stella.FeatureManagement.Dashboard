# Documentation

Knowledge left behind by agents and humans working on this repository, organized by type.
Each folder's `README.md` is the index of its contents — keep it up to date whenever a
document is added, renamed, or removed. Docs files link downward — into their own folder or
deeper — never up to this file or to CLAUDE.md.

| Folder (link = index) | Contents |
| --- | --- |
| [adrs/](./adrs/README.md) | Architectural and design decision records |
| [specs/](./specs/README.md) | Specifications: what to build and why |
| [plans/](./plans/README.md) | Plans produced by agents, skills, or workflows |
| [memories/](./memories/README.md) | Durable facts agents learned about this repository |
| [learnings/](./learnings/README.md) | Lessons learned: failures, gotchas, corrections |

This structure is defined by the `stella-agentic-workflow-docs` plugin from
[stella.agentic.workflow](https://github.com/rochar/stella.agentic.workflow).
